Bynji Privacy Policy

Effective 30 August 2026

Bynji is a private, local-first browser extension that saves video playback progress and viewing history. It has no advertising, analytics, telemetry, developer-operated server, or user account.

Information Bynji handles

To provide its Library, Resume, Trail, Insights, metadata discovery, and reliability features, Bynji may process and store:

  • The normal page URL and website domain where a video is played.
  • Descriptive page and player metadata such as title, series, season, episode, content type, duration, release year, and artwork URL when supplied by the page.
  • Playback position, completion state, watched ranges, timestamps, and bounded playback-session events.
  • Locally inferred identity relationships, user corrections, Resume choices and dismissals, source availability, and sanitized reliability diagnostics.
  • User-selected settings, including appearance, subtitle preference, excluded websites, and Resume behavior.

Bynji does not intentionally collect or save video streams, media manifests, DRM information, cookies, authentication headers, licence-server information, passwords, payment information, clipboard contents, download history, or incognito activity.

Chrome Web Store data categories

Chrome treats information processed or stored only on a user's device as handled user data. Bynji therefore discloses the following Chrome Web Store categories:

  • Web history: the URL, domain, media or page title, and viewing timestamps for qualified video pages.
  • User activity: video playback position, watched ranges, completion state, Resume decisions, and user corrections. Bynji does not log general clicks, keystrokes, mouse movement, or scrolling.
  • Website content: bounded page and player metadata needed to identify the current video, such as title, series, season, episode, duration, content type, selected controls, and artwork URL.

Purpose and consent

This information is used only to provide and improve Bynji's disclosed user-facing features. On a new installation, Bynji does not activate page observation or save viewing activity until the user accepts the first-run disclosure. Tracking can later be disabled globally or for selected websites in Settings.

Storage, retention, and deletion

Viewing information is stored in the browser extension's local IndexedDB database. It remains there until the user deletes entries, resets Bynji data, removes the extension according to browser behavior, or imports a file they explicitly selected. JSON, Markdown, and text exports are created locally only after a user action.

Bynji does not transmit viewing information to the developer or to an analytics, advertising, metadata, or AI service. The active metadata-discovery path does not make external provider calls.

Permissions

  • HTTP and HTTPS page access recognizes active playback and obtains bounded page/player metadata.
  • Storage and unlimited storage preserve the local viewing library.
  • Web navigation keeps playback attached to the correct presentation after navigation or player replacement.
  • Alarms perform bounded local maintenance.
  • Side Panel provides an optional browser-owned Bynji interface.

Incognito access is disabled in the extension manifest.

Remote code

Bynji does not execute remote code. Its executable JavaScript is included in the installed Manifest V3 package. It does not load remote scripts or WebAssembly, evaluate fetched strings as code, or fetch commands for execution. Page text, structured metadata, and serialized page state are treated only as data and are not evaluated as code.

Sharing, security, and human access

Bynji does not sell, rent, share, or use viewing information for advertising, credit decisions, profiling, or generalized market research. The developer cannot remotely access locally stored viewing information. Users may intentionally share an export under their own control.

Bynji validates extension messages and imported records, uses Manifest V3 with locally packaged executable code, and sanitizes sensitive query parameters in bounded diagnostics. Users should protect exported plaintext files as private viewing history.

Chrome Web Store Limited Use disclosure

The use of information received from Google APIs will adhere to the Chrome Web Store User Data Policy, including the Limited Use requirements.

Changes and contact

Material changes will update this policy and its effective date. Questions and privacy requests can be sent to bynjiapp@proton.me.
